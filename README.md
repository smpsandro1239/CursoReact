Plataforma LMS de elite construída com **React 19**, **Zustand**, **Framer Motion** e **Tailwind CSS**.

## 🌟 Novidades da Versão 2.0 (Evolution)

- **40 Aulas Profissionais:** Conteúdo expandido com foco em performance e arquitetura.
- **Gamificação Avançada:** Sistema de XP, Níveis, Streaks e GamificationBar persistente.
- **Novo Motor de Quiz:** Múltiplas perguntas por aula, feedback dinâmico e dicas progressivas.
- **Editor v2:** Laboratório prático integrado com suporte a execução e XP por validação.
- **TypeScript & Zod:** Infraestrutura de dados robusta e segura.
- **Certificado Elite:** Geração de PDF profissional com métricas de aprendizagem.

## 🛠️ Início Rápido

```bash
cd react-course
npm install
npm run dev
```
